# Code of conduct

## Our pledge

We want ModelPick to be a place where the best argument wins, regardless of who makes it. We pledge to make participation harassment-free for everyone.

## Expected behaviour

- Critique the claim, the data, or the code — not the person.
- Bring sources for factual claims about models and prices.
- Assume good faith; ask a clarifying question before escalating.
- Accept that "I don't know" is a valid answer, especially about model quality.

## Unacceptable behaviour

- Harassment, discrimination, or personal attacks.
- Publishing private information without consent.
- Fake benchmark data, fake stars, or coordinated voting.
- Spam, undisclosed promotion, or vendor astroturfing.

## Enforcement

Report concerns to the maintainer via GitHub. Consequences range from a warning to a permanent ban. Reports are handled privately.
