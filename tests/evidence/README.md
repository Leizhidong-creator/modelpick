# Test evidence

This folder contains the visual and machine-readable evidence for ModelPick 0.1.0.

## Images

| File | What it shows |
|---|---|
| `terminal-pick.png` | Real CLI output for a 3D game-asset decision |
| `terminal-plan.png` | Real CLI output for a multi-step launch-video plan |
| `benchmark.png` | Decision benchmark: 115 runs, all thresholds |
| `cost-quality.png` | Quality vs cost per solved task for the coding node |
| `architecture.png` | Data → engine → agent surfaces |
| `social-preview.png` | Repository social preview (1280×640) |
| `site-desktop.png` | Landing page, 1440px viewport |
| `site-mobile.png` | Landing page, 390px viewport |

Generated by `python scripts/make_assets.py` from the actual CLI and benchmark JSON. Site screenshots use Playwright Chromium.

## Machine-readable results

| File | Contents |
|---|---|
| `../results/benchmark-latest.json` | 115 development runs, per-scenario picks, failures, metrics |
| `../results/report.html` | Human-readable development report |
| `../results/holdout-latest.json` | 35 held-out runs |
| `../results/holdout.html` | Human-readable held-out report |

## Reproduce

```bash
node bench/run.js
node bench/holdout.js
python scripts/make_assets.py
npx playwright screenshot --viewport-size "1440,1100" --full-page docs/index.html tests/evidence/site-desktop.png
npx playwright screenshot --viewport-size "390,844" --full-page docs/index.html tests/evidence/site-mobile.png
```

## Notes on honesty

- Benchmark labels are expert-authored, not independently crowdsourced. See `bench/METHODOLOGY.md`.
- Quality scores for media are priors from vendor/spec evidence, not measured outputs.
- The screenshots are generated from the code in this repository at catalog `2026.11.19`. Re-running after a catalog update will change numbers.
