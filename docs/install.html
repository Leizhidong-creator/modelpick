Installation

ModelPick in 60 seconds.

One command installs the CLI and MCP server. Then one command opens the page where you paste a provider key. No build step. No runtime dependencies.

Node.js 20+Windows · macOS · LinuxZero telemetryKeys stay local
Windows

Double-click setup

Download the launcher and run it. It uses npx, so it does not need admin rights.

中文：下载后双击运行即可，不需要管理员权限。

Download start-modelpick.cmd
Windows may warn that the file came from the internet. Choose Keep, then Run. The launcher only runs npx --yes --package=modelpick@latest modelpick keys --ui.
macOS / Linux · or Windows terminal

Install globally

Gives you a permanent modelpick command.

npm install -g modelpick

No admin rights? Use the no-install path:

npx --yes --package=modelpick@latest modelpick keys --ui
Then

Connect one provider

1Run modelpick keys --ui
2Click “Get a key” for your provider
3Paste it, then click “Save & test”
modelpick keys --ui
npm package ↗ MCP Registry ↗
Verify

Check that it worked

modelpick --version
modelpick keys list
modelpick run --status

You should see 0.2.2 (or newer), a provider table, and a local Ollama answer if Ollama is running. No key is needed for local models.

If something goes wrong

'modelpick' is not recognized / command not found

You probably ran npm install modelpick, which installs into ./node_modules and does not add a PATH command. Either install globally with npm install -g modelpick, or run npx modelpick keys --ui in that folder.

Ok to proceed? (y) from npx

Type y and press Enter. To skip the prompt next time, add --yes: npx --yes --package=modelpick@latest modelpick keys --ui.

'#' is not recognized in CMD

# is a bash comment, not a Windows CMD comment. Copy only the command lines from this page, not the explanatory lines.

The browser did not open

The terminal prints a URL such as http://127.0.0.1:54321/keys?token=.... Copy it into your browser. The page is local-only and the token expires with the server.

I do not have an API key

You can use ModelPick without one for recommendations. To run a local model, install Ollama, then run ollama pull qwen2.5:0.5b and modelpick run --status.
